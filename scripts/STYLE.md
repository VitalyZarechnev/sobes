# Шаблон страниц вики (для авторов)

Язык — русский, термины — в оригинале при первом упоминании (замыкание / closure).
Уровень — senior/lead: не пересказ азов, а глубина, нюансы, trade-offs и «почему».

## Структура README.md раздела

```markdown
# <Номер>. <Название раздела>

> Сколько дней из плана, на что сделать упор, как связано с другими разделами.

## Прогресс раздела
- [ ] [Тема 1](01-xxx.md)
- [ ] [Тема 2](02-xxx.md)
...

## Как готовиться
Короткий порядок работы + главные источники.

## Самопроверка раздела (топ-10 вопросов)
1. ...
```

## Структура страницы темы

```markdown
# <Тема>

> ⏱ ~N ч · 🎯 Что должен уметь senior/lead по этой теме (1–2 строки)
> ← [Раздел](README.md) · [Роадмап](../ROADMAP.md)

## Чек-лист
- [ ] Прочитал теорию
- [ ] Разобрал примеры кода руками
- [ ] Ответил вслух на вопросы ниже
- [ ] Решил практические задачи
(+ 3–6 пунктов по конкретным подтемам)

## Теория
Подзаголовки ###, примеры кода с комментариями, таблицы сравнения,
подводные камни («🪤 Ловушка:»), «💡 На собеседовании:» — как формулировать ответ.

## Вопросы с собеседований
<details><summary>Вопрос?</summary>

Ответ: сжато, как сказать вслух за 1–2 минуты + что упомянуть для senior/lead.
</details>
(8–15 вопросов)

## Практика
Задачи «предскажи вывод» / реализуй / спроектируй, с решением в <details>.

## Источники
Только реально существующие URL, в которых вы уверены.
```

Правила:
- Чекбоксы `- [ ]` используются ТОЛЬКО для отслеживания прогресса (скрипт их считает).
  В обычных списках чекбоксы не применять.
- Ссылки между страницами — относительные Markdown-ссылки.
- Страница 150–450 строк. Без воды, без эмодзи-мусора кроме перечисленных маркеров.
- Код — TypeScript/JavaScript, корректный, современный (ES2024+, TS 5.x, React 19, Vue 3.5).
