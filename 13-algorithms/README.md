## Как готовиться
1. Прочитать [01-complexity](01-complexity.md) и выучить алгоритм решения задачи на интервью (уточнить → примеры → брутфорс → оптимизация → код → тесты → сложность).
2. По каждой теме: прочитать паттерн, решить задачи **easy** без подсказок, затем **medium**. Застряли на 20–25 минут — прочитать эталон, через 2–3 дня решить снова (отметка «Повторить» в [дневнике](#/journal)).
3. Проговаривать решение вслух — на интервью оценивают ход мысли не меньше, чем результат.
4. Во фронтенд-интервью чаще встречаются задачи из [08-frontend-algorithms](08-frontend-algorithms.md) (деревья DOM/JSON, debounce, LRU, плоский список → дерево), чем «чистый» LeetCode hard.

8. Как распознать задачу на DP и перейти от рекурсии с мемоизацией к таблице?
